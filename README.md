# Globit V2

Globit V2 is the second iteration of **Globit**, a location-based social media application where users can geotag photos onto a 3D globe and explore posts from around the world.

This project was my **first full-stack application** and marked a significant step in my web development journey. The original version of Globit was built with **vanilla JavaScript**, while this second iteration was rebuilt using **React**, resulting in a more maintainable codebase and a much smoother user experience.

## Features

- 🌍 Explore posts pinned to an interactive 3D globe
- 📸 Geotag images anywhere in the world
- 📰 Browse posts in a traditional social media feed
- 🏅 Collect location stamps by posting from special destinations
- 👤 User authentication and cloud-based data storage

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Supabase
  - Authentication
  - PostgreSQL Database
  - Storage

## Evolution from V1

Compared to the original version, Globit V2 introduced:

- Complete frontend rewrite from Vanilla JavaScript to React
- Improved component architecture
- Better state management
